* Key Design Decisions
  - Minimal (user, 2026-10-16): --no-root-pypi at devpi-init, --threads 4. A real devpi with its PyPI
    mirror runs in a dedicated VM. Enabled in the rawBisosCbm set.
  - Isolated venv: devpi-server 6.20.3 requires setuptools<=81 and asc has 84.0.0. Back to asc when that
    changes.
  - Accounts by a oneshot unit, not assemble: cbs_materialize runs sbom -> assemble -> units, so the
    server is not running during assemble. The script is code (rewritten each sbom run), not config.
  - --restrict-modify root,admin: devpi's default lets anyone create users and indexes.
  - --outside-url http://devpi.internal, so devpi-web's links are right behind nginx.
  - devpi-client via pipx at its pin (bisos.sbom ignores versions in pipxPkgsList).
  - Out of chain (under git): the cbm-package-authorship skill; bxGenesis/start/rawBisosCBMs/README.org
    (the catalog: devpi minimal, enabled, dedicated-VM real home).
